# Issue #102 이동 불가 영역 자동 보정

## 목적

사용자에게 벽과 외곽을 별도 개념으로 요구하지 않고, 도면을 가져오면 이동할 수 없는 영역의
초안을 먼저 보여준다. 사용자는 기존 펜·브러시 도구로 잘못 표시된 부분만 추가하거나 삭제한다.

## 처리 흐름

```text
벽 추출 baseGrid + 원본 도면선(색상 CAD 선 포함)
→ 최대 512셀 작업 격자로 축소
→ 여러 closing 반경의 후보 생성
→ 이미지 테두리에서 flood fill
→ 가장 큰 닫힌 내부 영역 선택
→ 편집 가능한 128개 이하의 정규화 경계로 단순화
→ 기존 outsideMask와 사용자 편집 적용
→ resolved-mask.bin
```

원본 선은 외곽 추론용 임시 마스크에만 사용한다. 글씨·가구선이 최종 장애물로 추가되지 않으며,
최종 저장 형식과 CQBCore 계약도 바뀌지 않는다.

## 안전 장치

- 후보 면적이 전체의 5~80% 범위를 벗어나면 자동 제안을 사용하지 않는다.
- 닫힌 영역이 선 근거를 70% 미만 포함하면 자동 제안을 사용하지 않는다.
- 충분한 내부 면적을 만들지 못한 열린 도형은 기존 수동 지정으로 fallback한다.
- 자동 경계도 사용자가 동일한 편집 화면에서 다시 지정할 수 있다.

## 알려진 제약

- 중정, 여러 동이 분리된 도면, 실내·외 정책이 애매한 발코니는 별도 제품 결정이 필요하다.
- 원본 선 보조는 사진·텍스처가 많은 입력보다 흰 배경의 도면에 적합하다.
- 복수 동 또는 가느다란 연결부가 있는 도면은 가장 큰 닫힌 영역을 보수적으로 선택해,
  실제 이동 가능 영역 일부가 차단으로 제안될 수 있다.
- 자동 제안은 저장 전 사용자 확인을 대체하지 않는다.
