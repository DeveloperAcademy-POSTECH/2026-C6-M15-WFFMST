# #88 MemberApp 데모 기록 완료와 초기화

## 구현 범위

- 데모 녹화 중 별도 InstructorApp 없이 `데모 훈련 종료`를 실행한다.
- 기존 `ARRecordingService`가 만든 실제 영상 조각과 동선 샘플을 저장하고 기존 경로 보정을 실행한다.
- 보정 결과 화면을 표시한 뒤 서버 전송 대신 로컬 완료 진행률을 재현한다.
- 완료 시 해당 데모 실행의 파일과 상태만 정리하고 운영 참가 화면으로 돌아간다.
- 영상 마무리 또는 파일 저장에 실패하면 데모를 버리고 다시 시작할 수 있다.

## 저장 및 네트워크 경계

운영 기록은 `Application Support/Recordings/<recordingID>`에 유지한다. 데모 기록은 `Caches/DemoRecordings/<runID>/<recordingID>`에 저장해 경로부터 분리한다. 데모 완료와 실패 취소는 현재 `runID` 디렉터리만 제거하며 운영 `Recordings` 및 다른 데모 실행 경로는 삭제하지 않는다.

데모 녹화는 `VideoChunkUploadQueue`를 만들지 않고 Recording, VideoChunk, TrackResult Repository를 호출하지 않는다. `MemberDemoUploadSimulator`는 로컬 영상과 보정 결과 확인 단계를 진행률로 표시할 뿐 네트워크 의존성을 갖지 않는다.

## 사용자 흐름

1. 데모 훈련을 시작하고 실제 카메라·AR 영상과 동선을 기록한다.
2. `데모 훈련 종료`를 누르고 확인한다.
3. 저장·경로 보정이 끝나면 영상과 보정 결과를 확인한다.
4. `데모 처리 계속`을 눌러 로컬 완료 진행률을 확인한다.
5. `데모 종료`를 누르면 데모 파일이 삭제되고 운영 PIN 참가 화면으로 돌아간다.

## 검증

- 로컬 완료 단계가 단조 증가해 100%에서 끝나는지 테스트한다.
- 데모 실행 디렉터리 삭제 후 운영 기록 파일이 보존되는지 테스트한다.
- 기존 데모 진입·훈련 시작·Repository 격리 테스트를 함께 실행한다.
- 실제 iPhone에서 카메라·AR 기록부터 종료, 보정 결과, 완료 및 재진입 초기화를 확인한다.

CQBCore 모델, Firebase 저장 경로와 파일 형식은 변경하지 않았다.
