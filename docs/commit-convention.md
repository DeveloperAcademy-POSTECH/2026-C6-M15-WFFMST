# 커밋 컨벤션

```
<이모지> <type>: <제목>

<본문: 무엇을, 왜>  선택
```

예: `✨ feat: PIN 입력으로 세션 입장`

## type

| 이모지 | type | 언제 |
| --- | --- | --- |
| ✨ | `feat` | 새 기능 |
| 🐛 | `fix` | 버그 수정 |
| ♻️ | `refactor` | 동작 그대로, 구조만 개선 |
| 🎨 | `style` | 포맷, 이름 정리 |
| 💄 | `ui` | 화면, 디자인 수정 |
| ✅ | `test` | 테스트 |
| 📝 | `docs` | 문서, 주석 |
| 🔧 | `chore` | 빌드·프로젝트 설정 |
| ➕ / ➖ | `deps` | 패키지 추가 / 제거 |
| ⚡️ | `perf` | 성능 개선 |
| 🗃️ | `schema` | 데이터 계약 변경 |
| 🔒️ | `security` | 보안 규칙, 권한 |
| 🍱 | `asset` | 이미지, 도면, Fixtures |
| 🚑️ | `hotfix` | 급한 수정 |
| ⏪️ | `revert` | 되돌리기 |
| 🎉 | `init` | 프로젝트 시작 |

## 규칙

1. 제목은 한국어, 50자 안쪽, 마침표 없이 "~추가", "~수정"으로 끝낸다
2. 한 커밋에 한 가지 일만 담는다
3. `schema` 커밋은 본문 필수: 바꾼 필드, 이유, schemaVersion 변화
4. 이모지는 `:sparkles:` 말고 문자 그대로 ✨ 쓴다
