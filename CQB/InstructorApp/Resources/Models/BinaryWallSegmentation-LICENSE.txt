Model provenance
----------------

This package was initialized from Yytsi/floorplan-to-3d-walls and fine-tuned
for binary wall segmentation using phungpx/cubicassa5k-coco, a repackaging of
the CubiCasa5K dataset.

CubiCasa5K is licensed under the Creative Commons Attribution-NonCommercial
4.0 International License (CC BY-NC 4.0). This fine-tuned package is provided
in this repository for non-commercial research and educational use only.

Dataset: https://github.com/CubiCasa/CubiCasa5k
License: https://creativecommons.org/licenses/by-nc/4.0/
Repackaging: https://huggingface.co/datasets/phungpx/cubicassa5k-coco

Modifications
-------------

- Converted the source annotations into binary blocked/free labels
- Treated wall and window as blocked, and floor, door, and other as free
- Fine-tuned the segmentation model for the binary task
- Converted the trained weights to an FP16 Core ML package

Citation
--------

Kalervo, Ahti, Juha Ylioinas, Markus Haikio, Antti Karhu, and Juho Kannala.

Analysis." Scandinavian Conference on Image Analysis (SCIA), 2019.
