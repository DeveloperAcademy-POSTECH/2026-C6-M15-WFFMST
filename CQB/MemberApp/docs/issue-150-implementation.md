## 화면 흐름

| 실행 환경 | 참가 후 이동 | 수동 설정 |
| --- | --- | --- |
| 운영, 월드맵 있음 | 카메라에서 재인식 | 세션 실행 후 10초 동안 유효한 도면 위치를 얻지 못하면 설정하기 표시 |
| 운영, 월드맵 없음 | 기존 출발 위치 설정 | 위치·방향 확인 후 카메라로 이동 |
| 데모 | 카메라에서 스캔 흐름 재현 | 화면 활성 상태에서 10초 후 설정하기 표시 |

이슈 본문의 월드맵 없는 운영 세션에 관한 두 항목은 서로 다른 진입 경로를 명시한다. 이번 작업은 대화에서 확정된 기존 수동 설정 유지 정책을 적용한다.

데모에는 실제 월드맵이 없다. 스캔 중 → 10초 후 설정하기 흐름만 재현하며, 실제 카메라 추적이 정상이어도 자동 위치 인식 성공으로 처리하지 않는다. AR 미지원 시뮬레이터에서도 화면이 활성 상태이면 동일한 대기 흐름을 체험할 수 있다. 화면 이탈·앱 비활성화 시 대기를 취소하고 복귀하면 다시 10초를 센다. 수동 설정을 선택한 뒤에는 스캔 흐름을 반복하지 않는다. 실제 녹화 시작에는 기존처럼 AR 추적 안정화가 필요하다.

카메라에서 수동 설정으로 진입했다면 뒤로가기는 카메라로 복귀한다. 수동 설정 선택 시 월드맵을 해제하며, 이후 재인식을 반복하지 않는다. 최초 수동 설정으로 진입한 운영 세션의 뒤로가기는 참가 화면으로 복귀한다.

## 상태와 책임

- `MemberStore`: 위치 설정 상태, 진입 경로, 재인식 제한 시간, 화면 전환과 서버 준비 상태 보고.
- `MemberWorldMapLoader`: 참조·해시·스키마 검증, LZFSE 해제, 보안 아카이브 복원. 복원은 별도 실행기에서 수행하고 결과를 Store에 전달한다. 압축 해제는 최대 128MiB로 제한한다.
- `ARRecordingService`: 단일 카메라/녹화 세션, `initialWorldMap`, 추적 상태와 자세 전달, 실제 녹화 시작 프레임의 위치 확정.
- `WorldMapPositionCalculator`: AR 자세를 도면으로 변환하고 유효한 이동 가능 출발점과 수평 방향을 검사한다.
- View: Store에서 확정한 준비 상태와 안내·설정하기 버튼을 렌더링한다.

공통 모델·Repository·저장 경로·파일 형식은 기존 계약을 사용한다. 상태와 변환 결과는 MemberApp 내부 타입이다.

## 재인식과 녹화 기준

다운로드와 카메라 권한 요청 동안에는 10초를 세지 않는다. 실제 AR 세션을 실행한 뒤 제한 시간을 시작한다. 10초가 지나도 인식은 계속 시도하고, 버튼을 누르기 전에 인식에 성공하면 수동 전환 안내를 해제한다.

정상 추적과 유효한 도면 위치가 확보되면 제한 시간을 취소한다. 기존 방향 안정화 조건을 통과해야 준비 완료가 된다. 추적을 잃으면 자동 출발 위치와 준비 상태를 무효화한다. 앱 비활성화·카메라 중지 시 타이머를 취소하고, 새로운 카메라 실행에서 다시 인식한다.

자동 모드에서는 저장된 교관의 출발점을 복사하지 않는다. 현재 카메라 자세와 저장된 `alignment`를 사용한다. 권한 처리 중 이동할 수 있으므로 실제 첫 녹화 프레임을 기준으로 출발 위치·방향을 다시 계산한다. 동선의 상대 원점도 같은 프레임이며 회전과 축척은 월드맵 변환 값을 사용해 중복 회전을 방지한다. 자동 방향점은 방향 벡터를 보존하기 위해 도면 밖에 있을 수 있으나 출발점은 반드시 도면 내부 이동 가능 영역이어야 한다.

수동 모드는 기존 선택 위치·방향과 카메라 시작 방향을 사용한다. 두 모드 모두 위치·방향과 AR 추적이 준비돼야 녹화를 시작한다. 미준비 상태에서 운영 훈련이 시작된 경우 참가를 종료하는 기존 정책을 유지한다. 시작 요청 대기 중 세션이 종료되면 기존 녹화 시작 취소 경로를 사용한다.

월드맵 다운로드·복원에 실패하면 참가 화면에 공간 정보 오류를 표시하고 참가 재시도를 허용한다. 이를 재인식 제한 시간 초과나 월드맵 없는 세션으로 처리하지 않는다.

### 남은 확인

- 실제 교관 앱에서 저장한 월드맵의 다운로드·복원 성공과 동일 공간에서의 재인식.
- 실제 재인식 10초 초과 → 설정하기 → 수동 위치·방향 선택 → 카메라 복귀 → 녹화 → 업로드의 전체 탭 경로.
- 자동 인식 후 위치를 옮기거나 방향을 바꾼 뒤 녹화했을 때 첫 프레임 출발 좌표와 실제 도면 위치의 일치.
- 실제 앱 비활성화·카메라 가림·권한 변경·재인식 중단 후 복구와 운영 서버 준비 보고.

시뮬레이터는 실제 AR 재인식과 녹화를 검증할 수 없다. Store의 경로 전환과 녹화 취소는 자동 테스트로 확인했으며, 실제 앱의 전체 탭 경로와 위 AR 동작은 실기기 확인이 필요하다.

### Issue #167 압축 복원 보완 — 2026-11-03

- `MemberWorldMapLoader`에서 파일 크기 → 설정 파일 해시·디코딩 → 참조·저장 바이트 크기·아카이브 해시 → 압축 해제 → ARKit 복원 순서로 검사한다. 파일별 다운로드 제한은 [Repository 계약](../../../docs/repositories.md)을 따른다.
- LZFSE는 고정 버퍼로 한 번만 읽으며 해제하고, 기존 원본 상한인 128MiB까지 허용한다. 상한을 1바이트라도 넘으면 결과를 사용하지 않는다. 종료 표식이 없는 잘린 스트림을 거부한다. Apple 압축 해제 API는 종료 이후 바이트를 허용할 수 있으므로, 파일 변경·추가 바이트는 압축 해제 전 저장 파일 전체의 크기·해시 검증으로 차단한다.
- 압축 해제 도중 취소를 확인하고, 취소한 작업에는 참가 실패 안내를 표시하지 않는다. 기존 `.none` 아카이브는 압축 해제 없이 복원한다.
- 공간 정보 손상·누락·용량 초과·압축 해제 실패·ARKit 복원 실패를 네트워크 오류와 구별해 참가 화면에 안내한다. 파일 복원 실패 시 참가 등록을 중단하고 재시도를 허용하는 기존 정책을 따른다. 수동 설정 안내는 AR 세션 재인식의 제한 시간이 지난 경우에 적용한다.
- 테스트는 InstructorApp과 같은 Foundation LZFSE 출력의 호환성, 기존 `.none` 아카이브 바이트 보존, 실제 128MiB 경계, 손상·잘림·추가 데이터, 메타데이터 무결성, 취소 및 참가 실패·재시도를 다룬다. 실기기 ARWorldMap 복원·공간 재인식은 별도로 확인해야 한다.
- 검증: iPhone 17 / iOS 27.0 시뮬레이터에서 MemberApp 빌드 및 관련 38개 테스트 통과(파일 검증·압축 해제 15, 위치 설정·참가 오류 13, 녹화 시작 수명주기 10). 결과는 `/private/tmp/cqb-167-member-final.xcresult`에 보관한다.
