# InstructorApp 화면 흐름과 상호작용 정책

교관 앱의 현재 MVP 동작을 정리한다. 공통 책임·의존성 규칙은 [공통 아키텍처](../../../docs/architecture.md), 코드 작성 규칙은 [AGENTS.md](../AGENTS.md)를 따른다.

## 도면 등록

도면 목록 → 생성 → 이름 입력·파일 선택 → 장애물·외곽 편집 → 축척 설정 → 최종 확인·등록 → 도면 목록

- 도면 생성 화면의 뒤로 가기는 도면 목록으로 이동한다. 도면 목록의 뒤로 가기는 홈으로 이동한다.
- 파일 선택은 PNG/JPEG를 지원하며 갤러리 선택이나 서버 업로드가 아니다.
- 자동 추출 결과는 초안이며 사용자가 장애물과 외곽을 검수한다.
- 편집에는 Pencil·한 손가락을, 이동·확대에는 두 손가락을 사용할 수 있다. 이동 도구에서는 한 손가락 이동도 지원한다.
- 파일 교체는 처리 성공 시에만 반영한다. 실패·취소 시 기존 편집을 유지한다.
- 획 재계산 중 직전 미리보기를 유지하고 매 획마다 로딩을 표시하지 않는다. 새 결과가 준비되기 전에는 다음 단계 진행·등록을 막는다.
- 이름·이미지·최종 격자·외곽·축척이 유효하고 최종 확인을 마쳐야 등록할 수 있다.
- 등록한 도면은 세션 생성 화면에서 선택할 수 있으며 앱 종료 후 복원되지 않는다.
- 공통 도면 계약·Firebase 연결, 상세 조회·수정·삭제와 동선 보정은 현재 구현 범위에 포함하지 않는다.

처리 정책의 수치와 검증 이력은 [Issue #8 구현 기록](issue-8-implementation.md)을 참고한다.

## 팀 준비와 훈련 시작

- 준비 완료 대원이 한 명도 없으면 훈련을 시작할 수 없다.
- 미준비 대원이 일부 있으면 훈련 시작 시 확인을 거쳐 미준비 대원을 현재 세션에서 일괄 제외한다.
- 확인을 취소하면 팀 준비 화면을 유지한다.

## AAR

공통 값 모델·선택 제한·검증 기준은 [공통 데이터 계약 1.6](../../../docs/shared-data-contract.md#16-aar-설정)을 따른다. 아래는 교관 앱에서의 상호작용과 연결 상태다.

### 현재 앱 내부 Mock 흐름

- 훈련 종료 후 AAR에 처음 진입하면 동선 모드에서 실제 훈련 참가 대원을 모두 선택한다. 훈련 시작 시 제외된 대원은 선택하지 않는다.
- 동선과 영상은 같은 선택값을 사용한다. 설정창을 닫았다 열거나 허용된 모드 전환을 해도 선택을 유지한다.
- 아무도 선택하지 않을 수 있다. 영상에서는 선택 없음 안내를 표시하며, 빈 선택을 자료 로딩 중이라는 의미로 사용하지 않는다.
- 인원 제한을 넘는 영상 전환·대원 추가 요청은 Store가 거부하고 기존 모드·선택을 유지한다. View는 안내를 표시하며 선택값을 임의로 줄이지 않는다.
- 예: 동선에서 6명 선택 → 영상 전환 거부·6명 유지 → 사용자가 4명으로 줄임 → 영상 전환 → 동선으로 돌아와도 4명 유지.

### 공통 모델 연결 시 지킬 경계 — 후속 작업

- 현재 구현은 앱 내부 `AARMode`·Mock 참가자 ID를 사용하며 공통 AARSettings에 연결되지 않았다. #20은 공통 값 모델·검증·Fixture까지이고 이 앱의 View/Store 교체는 후속이다.
- 실제 세션·참가자 목록을 확보한 뒤 공통 식별자로 초기 설정을 구성한다. 설정 미로딩을 빈 선택으로 채우거나 다른 세션의 선택을 재사용하지 않는다.
- 선택 의도와 자료 로딩을 분리한다. 선택한 대원의 영상·보정 결과가 미확보·실패·로딩 중이라도 자동으로 선택을 해제하지 않고 대원별 상태를 표시한다. 현재 Mock 흐름으로 실제 자료 조회·재생이 검증된 것은 아니다.
- 수동 시간 조정은 MVP에서 제외한다. 일반 재생 위치 조작과 수동 대원별 시간 오프셋을 혼동하지 않는다. 영속 저장·재진입 복원·기기 간 설정 동기화는 구현하지 않았다.
