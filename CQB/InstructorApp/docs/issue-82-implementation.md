# Issue #82 데모 AAR 샘플 동선·영상

## 목적

TestFlight 외부 심사자가 별도 대원 기기나 운영 데이터 없이 교관 앱의 훈련 종료부터 AAR까지 확인할 수 있게 한다.

## 구현 범위

- 데모 기록은 훈련 종료 직후 `finishing`을 내보내고 1초 뒤 3명 모두 `done`으로 전환한다.
- 데모 실행 환경은 하나의 메모리 세션·대원·기록 저장소를 `InstructorStore`와 `AARStore`에 함께 주입한다.
- 세 참가자에게 서로 다른 12초 동선을 제공하며, 좌표는 데모 도면의 1,200×800 픽셀 좌표계를 사용한다.
- 영상 모드에서는 앱 번들에 포함한 12초 샘플 영상을 선택한 참가자별 타임라인에 맞춰 재생한다.
- 샘플 영상은 FFmpeg의 색상·격자·도형 필터로 직접 생성했으며, 스캔 라인과 마커가 매 프레임 이동해 재생·일시 정지·탐색 결과를 눈으로 구분할 수 있다.
- 데모 종료 또는 재시작 시 Store와 AAR 재생 상태를 모두 초기화한다.

## 경계

- 데모 Repository는 `InstructorApp` 내부에만 있고 Firebase·Storage에 접근하지 않는다.
- `CQBCore` 모델 및 Repository 계약은 변경하지 않는다.
- 운영 모드의 세션, 기록, 동선, 영상 경로는 변경하지 않는다.
- 샘플 영상은 640×360, 30fps, H.264, 무음 형식이며 식별 가능한 인물, 음성, 개인정보 및 제3자 저작물을 포함하지 않는 프로그램 생성 그래픽이다.

## 검증

- InstructorApp Debug 시뮬레이터 빌드
- `InstructorDemoScenarioTests`: 홈부터 AAR 진입, 3개 동선, 번들 영상, 1·6·11초 프레임 변화, 재생·일시정지, 초기화
- InstructorApp Release 빌드 및 번들 리소스 포함 여부
- 실제 iPad에서는 데모 훈련 종료 후 AAR 자동 진입, 참가자 선택, 동선 이동, 영상 재생과 다시 시작을 확인한다.
